# LoArchive v2.1.0 更新介绍

> **新功能：彩蛋（回礼）下载支持！** 2.0 重构后的第一个功能版本。

## 🥚 彩蛋（回礼）下载

Lofter 的「彩蛋」功能允许作者把结局、番外或隐藏内容放在彩蛋栏中，读者解锁后可见。本版本支持在下载时**一并保存你已解锁的彩蛋**：

- 使用「单篇保存」下载一篇帖子时，会自动检测它是否带有彩蛋，并把**你当前账号已解锁**的彩蛋一并保存
- 彩蛋正文保存为 `彩蛋-标题.txt`（含原帖链接头），图片按原格式落盘，与普通下载内容并列存放
- 未解锁的彩蛋会在任务日志中明确提示「需先在 Lofter 中解锁再重新下载」，不会丢失任何内容

### 边界与说明

- **工具不会代替你支付**：解锁彩蛋需要在 Lofter 客户端中完成（送礼/粮票），工具只下载已解锁的内容——未解锁的连资源 ID 都拿不到，这是平台机制
- 彩蛋接口按移动端方式鉴权，请在「设置」中使用**手机号登录或 Lofter ID 登录**方式的授权码
- 当前接入「单篇保存」流程；作者文章、喜欢/推荐等批量流程的接入在评估中

## 🔧 其他改进

- CI 测试工作流现在会先构建前端再跑后端测试，与真实运行环境一致
- 修复 Tests 工作流在重构后未构建前端产物导致的误报
