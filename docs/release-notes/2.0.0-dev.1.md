# LoArchive v2.0.0-dev.1 更新介绍

> 这是 **2.0 正式版之前的第一个开发预览版**：整个应用完成了一次彻底重构——界面全部重写、后端深度加固。功能与 1.2 保持一致，欢迎尝鲜并反馈问题；正式版将在此基础上打磨细节。

## ✨ 全新界面

- **界面组件化重写**：从单文件页面重构为 Vue 3 + TypeScript 组件化应用，布局、层级与交互全面梳理，但保留了熟悉的青色主题与原版 Logo
- **三套主题完整保留**：默认 / 深色 / 黑白块，全部由统一的设计令牌派生，主题切换即时生效且观感一致（黑白块不再是"逐个组件补丁"）
- **新增全局任务坞**：在任何页面都能看到下载进度、展开完整运行日志，并且**新增了「停止」按钮**——旧版进度条只在收藏夹页面可见、也没有停止入口，这是本次最大的体验修复
- **下载历史全新升级**：搜索防抖、类型/来源筛选、统计一目了然；删除与清空前有确认对话框，新增一键复制文件路径
- **新手引导重做**，并尊重系统的"减少动态效果"设置
- **无障碍改进**：键盘可完整操作导航与模式选择、清晰的焦点指示、图标按钮均带文字标注
- **字体本地内置**（Noto Sans SC / Material Symbols），不再依赖 Google Fonts 在线加载，离线环境观感一致

## 🔧 后端深度重构

- **下载历史迁移到 SQLite**：查询性能与数据安全性大幅提升；首次启动会自动合并旧版 `download_history.json` 并将源文件备份为 `.bak`，数据无缝衔接
- **安全加固**：本地服务只监听 `127.0.0.1`（不再暴露到局域网）；跨域白名单收紧到应用自身来源；桌面窗口启用内容安全策略（CSP）；配置统一存放到系统应用数据目录（含 Lofter 登录令牌，不再散落在程序目录）
- **API v2 规范化**：正确的 HTTP 状态码 + Pydantic 响应模型 + 统一错误体；新增 `/api/version` 作为版本号的单一来源
- **统一日志系统**：控制台 + 数据目录内的滚动日志文件 `loarchive.log`；清除了大量"静默吞掉错误"的历史包袱，问题可追溯
- **代码治理**：爬虫公共逻辑收敛到单一模块、两份 PDF 模板合并为一套参数化模板；抓取与导出行为与 1.2 保持一致

## 📦 升级与数据迁移

- **无需手动迁移**：首次启动会自动把旧配置与下载历史导入新的数据目录（Windows 为 `%APPDATA%\LoArchive`），旧文件原样保留
- 主题偏好改为应用内切换（本地保存），后端设置中的 `dark_mode` 项移除
- 后端 API 有破坏性变更（v2 契约见仓库 `docs/api.md`），依赖旧接口的第三方脚本需要适配

## 🛠 开发者

- 前端工具链：Vue 3 + Vite + TypeScript + Pinia + Naive UI，测试 Vitest、类型检查 vue-tsc，CI 全覆盖
- `npm run dev` 一键启动后端 + 前端；`npm run tauri:dev` 全自包含桌面开发模式
- 版本号以 `loarchive/__init__.py` 为单一来源，`scripts/sync_version.py` 同步到各配置
